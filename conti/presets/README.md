# 콘티 preset (미리 채워진 콘티)

`conti/?preset=<이름>` 주소로 열면 아래 `.json` 파일을 자동으로 불러와 1·2·3번 칸에 채워 줍니다.
`?preset=<https://…/파일.json>` 처럼 **JSON 주소**를 바로 넣어도 됩니다(그 주소가 CORS를 허용할 때).

예) <https://heaven0115.github.io/harvestermusicmission/conti/?preset=example>

## 넣는 방법

1. 앱에서 콘티를 만들고 **콘티 관리 · 백업 → JSON으로 백업**을 눌러 파일을 받습니다.
2. 그 파일을 이 폴더에 `이름.json` 으로 올립니다.
3. `conti/?preset=이름` 링크를 만들어 문자·카톡으로 보내면, 누르는 것만으로 그 콘티가 열립니다.

## 주의

- 이 폴더는 **공개 저장소**입니다. 남의 악보(저작권 있는 스캔본·PDF)는 절대 넣지 마세요.
  악보가 든 콘티는 채팅으로 `.json` 파일을 받아 **콘티 파일 불러오기**로 넣는 것이 안전합니다.
- preset을 열면 지금 편집 중이던 콘티를 덮어씁니다. 필요하면 먼저 **JSON으로 백업**을 받아 두세요.
  (실수로 덮었을 때는 **↩ 직전 콘티 되돌리기**로 한 번 되돌릴 수 있습니다.)
