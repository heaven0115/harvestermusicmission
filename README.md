# 사역의 한 주 · MINISTRY WORKSPACE

효석패턴6 설교 원고와 주간 사역을 한 곳에서 준비하는 개인 사역 워크스페이스입니다.

- 배포 주소: https://heaven0115.github.io/harvestermusicmission/
- 정적 파일만 사용합니다 (`index.html`, `styles.css`, `app.js`, `data.js`).
- 검색 노출을 막기 위해 `index.html`에 `noindex, nofollow` 로봇 메타 태그를 두었습니다.
- 모든 수정은 브라우저 `localStorage`에 자동 저장되며, 화면 오른쪽 위의 **JSON 백업 / JSON 불러오기**로 파일을 주고받을 수 있습니다. `일정` 탭에서 직접 추가한 일정도 백업 파일에 함께 담깁니다.
- 주간 기준은 **월요일 시작 ~ 주일 종료**입니다 (`2026. 11.23 – 11.29`).

## 데이터

`data.js`의 초기 데이터는 `downloads/hyoseok6/2026-11-23_to_29/`의 효석패턴6 설교원고 7편(2026-11-23 ~ 11-29)에서 제목·본문·중심 주제·대지·여덟 구성(본문 분석 / 전후 맥락 / 모티프 / 신학·역사 배경 / 핵심 원어 / 30분 강단 설교 / 마무리 기도·찬송 / 소그룹 적용·묵상)을 그대로 옮겨 담았습니다.

## 자료 자동 생성

`설교 서재` 상세 화면의 상태 드롭다운 아래 **자료 자동 생성** 바에서 한 번에 만듭니다. 효석패턴6 여덟 구성을 읽어 만들며, 만들면 해당 상태가 자동으로 `완료`로 바뀝니다.

- **📊 PPT 만들기 (.pptx)** — PptxGenJS(CDN)로 16:9 와이드스크린 8장(표지 / 중심 구절·모티프 / 핵심 원어 / 첫째·둘째·셋째 대지 / 소그룹 적용 질문 / 마무리 기도·찬송)을 만들어 `{날짜}_{본문}_설교PPT.pptx`로 내려받습니다. 딥 포레스트 그린(`#1F5B3F`) + 크림 화이트(`#F8FAF8`) 톤입니다.
- **📖 성경공부 교재 만들기** — 본문 분석 · 전후 맥락 · 핵심 원어 · 소그룹 적용·묵상에서 본문 읽기, 분석 요약, 맥락, 원어 표, 대지별 정리, 나눔 질문, 이번 주 실천을 묶어 미리보기로 띄웁니다. 모달에서 **큰 글씨(18pt)** 전환, **인쇄 / PDF 저장**, **내용 복사**가 됩니다.
- **🙏 기도문 만들기** — 마무리 기도와 대지별 적용을 묶어 대지별 결단 기도 · 마무리 기도 · 추천 찬송으로 정리합니다. 인쇄·복사는 교재와 같습니다.
- **🖼️ 말씀 묵상카드 만들기** — 설교 제목·본문·중심 구절·핵심 메시지를 읽어 수채화 톤의 정사각 카드(**1080×1080**)를 HTML5 Canvas로 그립니다. 모달에서 배경 테마 4종(세이지 그린 · 웜 크림 골드 · 새벽 하늘 · 로즈 수채화)을 고르고, **중심 구절**과 **묵상 한 줄**을 그 자리에서 고쳐 미리보기에 바로 반영한 뒤 `{날짜}_{본문}_말씀묵상카드.png`로 저장합니다. 카드에는 설교 날짜·본문(개역개정)·제목·구절·묵상 한 줄과 하단 표기(왼쪽 `세리토스장로교회`, 오른쪽 `하베스터 뮤직 유효석 목사`)만 들어가고, `효석패턴6` 같은 패턴명은 넣지 않습니다.
- 생성 버튼 4개는 데스크톱·태블릿에서 2×2, 모바일에서 1열로 정렬됩니다.
- 인쇄는 `@media print`에서 사이드바·상단바·모달 도구 막대를 숨기고 교재·기도문 본문만 A4로 출력합니다.

## 과거 설교 아카이브

원드라이브(`heaven0115@outlook.com`)의 `/워드설교원고 파일`, `/Documents/워드설교원고 파일`, `/Documents` 최상위에 흩어져 있던 설교 `.docx` 원고를 모아 만든 읽기 전용 서재입니다. 원본 워드 파일은 저장소에 넣지 않고 정제한 텍스트만 담습니다.

- `archive/index.json` — 목록 메타데이터만(`id, year, date, service, scripture, title`). 첫 화면에서 이것만 읽습니다.
- `archive/{연도}.json` — 그 해 설교 본문(`id -> body`). 설교를 누를 때 해당 연도 파일만 받아 메모리에 캐시합니다. 연도가 확인되지 않은 원고는 `archive/unknown.json`에 있습니다.
- 읽기 화면: 날짜·예배·본문, 본문 전체, **내용 복사**, **인쇄 / PDF 저장**, **큰 글씨(18pt)**. 모바일·아이패드에서도 한 줄로 흐르고 인쇄는 A4로 나옵니다.
- 공개 저장소이므로 사역보고서·명단·교재·기도문·장례/추모 원고(고인 실명)·타인 원고는 모두 제외했습니다.
