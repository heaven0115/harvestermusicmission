# 사역의 한 주 · MINISTRY WORKSPACE

효석패턴6 설교 원고와 주간 사역을 한 곳에서 준비하는 개인 사역 워크스페이스입니다.

- 배포 주소: https://heaven0115.github.io/harvestermusicmission/
- 정적 파일만 사용합니다 (`index.html`, `styles.css`, `app.js`, `data.js`).
- 모든 수정은 브라우저 `localStorage`에 자동 저장되며, 화면 오른쪽 위의 **JSON 백업 / JSON 불러오기**로 파일을 주고받을 수 있습니다.

## 데이터

`data.js`의 초기 데이터는 `downloads/hyoseok6/2026-11-23_to_29/`의 효석패턴6 설교원고 7편(2026-11-23 ~ 11-29)에서 제목·본문·중심 주제·대지·여덟 구성(본문 분석 / 전후 맥락 / 모티프 / 신학·역사 배경 / 핵심 원어 / 30분 강단 설교 / 마무리 기도·찬송 / 소그룹 적용·묵상)을 그대로 옮겨 담았습니다.
