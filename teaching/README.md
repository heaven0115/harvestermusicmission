# 므두셀라 티칭 (Methuselah Teaching)

말씀 앞에서 설교를 살피는 코칭 워크스페이스.

설교 원고를 붙여 넣으면 열 가지 항목으로 채점하고, 원문 근거 문장을 하이라이트해 코멘트와 고쳐 쓴 예를 보여 줍니다. 설교 서재, 날짜별 성장 그래프, 기준 설교자 비교, 표현 모음까지 한 화면에서 이어집니다.

## 쓰는 법

1. **새 설교 분석**에서 제목·본문·성경 본문·날짜를 채웁니다.
2. **무료 모드**: `[분석용 프롬프트 복사]` → ChatGPT·Claude에 붙여넣기 → 돌아온 JSON을 `[응답 붙여넣기]`에 넣고 `[결과 불러오기 & 저장]`.
   **API 키 모드**: `설정`에서 OpenAI 또는 Anthropic 키를 넣으면 `[AI로 바로 분석하기]`로 원클릭 분석.
3. 리포트에서 총평·레이더 차트·항목별 점수·잘한 점·아쉬운 점(문제/방법/고쳐 쓴 예/연습 과제)을 봅니다.
4. **원문 하이라이트**에서 색 표시된 문장을 누르면 그 자리에서 코멘트가 열립니다.
5. **다시 쓰기 · 형식 변환**으로 원고를 새로 받고, 영어 설교는 **번역 대조**에서 문장별 원문↔한글을 봅니다.

## 설계

- 빌드 과정 없는 순수 정적 HTML/CSS/JS (`index.html`, `styles.css`, `app.js`)
- 외부 CDN·폰트·라이브러리 의존 없음. 차트(10각 레이더, 날짜별 꺾은선)는 인라인 SVG로 직접 그림
- 본문 기본 18px, 고대비, 아이보리·딥 네이비·버건디 서재 감성, 모바일·아이패드·데스크톱 반응형
- 자료는 브라우저 `localStorage`에만 저장. API 키도 브라우저에만 보관되며 분석 시 선택한 제공자에게만 직접 전송
- 설정에서 JSON 내보내기/가져오기로 백업·복원

## 열 가지 평가 항목

신학·말씀 — 성경 문맥 · 강해 충실도 · 그리스도 중심 · 복음과 은혜 · 교리 건전성
전달·목회 — 논리 흐름 · 공감과 적용 · 정서 안전 · 권위와 소통 · 언어와 예화

각 10점, 총점 100점.
