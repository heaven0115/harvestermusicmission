2 응답 붙여넣기

ChatGPT·Claude가 돌려준 응답을 그대로 붙여넣으세요. ```json 코드블록과 앞뒤 설명이 섞여 있어도 자동으로 벗겨 냅니다.

1 AI로 바로 분석하기

설정에서 API 키를 입력하면 원클릭 분석이 활성화됩니다. 키는 이 브라우저에만 저장되고, 분석할 때 선택한 AI 제공자에게만 직접 전송됩니다.

설교 서재

분석한 설교가 날짜순으로 쌓입니다. 본받고 싶은 설교는 기준 설교자로 지정해 비교해 보세요.

성장 그래프

내 설교의 날짜별 총점과 신학·전달 영역 평균 변화입니다. 선이 위로 향하는지보다, 어느 영역이 머무는지를 보세요.

기준 설교자 비교

본받고 싶은 설교(기준 설교)와 내 설교를 열 가지 항목으로 나란히 놓고 봅니다.

표현 모음
