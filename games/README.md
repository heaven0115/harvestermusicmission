## 기능

- 타이머 15·30·60초, 시작/멈춤, 리셋, 3초 이하 알림음, 종료 부저 (Web Audio API, 🔊 켜기/끄기)
- 정답 공개 토글, 문제 순서 섞기, 이전/다음 문제
- 팀 점수판 A~D (+/−, 초기화) — `localStorage`에 자동 저장
- 전체화면(⛶) — 프로젝터용으로 글씨가 커집니다
- 문제 편집(✎) — 브라우저에서 JSON 목록을 고쳐 저장(이 브라우저에만 저장), 기본 문제로 되돌리기
- 키보드: `Space` 타이머, `←`/`→` 문제 이동, `R` 정답, `S` 섞기, `F` 전체화면, `Esc` 닫기
- 모바일·태블릿·데스크톱 대응 (좁은 화면에서는 점수판이 서랍으로 열립니다)

## 데이터 고치기

`data.js`의 `window.CHURCH_GAMES` 배열이 게임 9종과 문제를 담고 있습니다.

```js
{ id, title, emoji, tone, tagline, howto, items: [ ... ] }
```

게임별 문제 형식:

- `shadow` — `{ cat, len, answers: [] }` (`answers`의 모든 낱말은 `len`글자)
- `relay` — `{ topic, sec, hint }` (`hint`는 쉼표로 구분한 예시 답)
- `chain` — `{ kind, prompt, answer, ref }`
- `pitch` — `{ text, target, dir }` (`target` 한 글자가 `text`에 포함, `dir`은 `높게`/`낮게`)
- `telepathy` — `{ word, hint }`
- `charades` — `{ cat, word, tip }`
- `orders` — `{ answer, hint, note, tiles: [] }` (`tiles`는 한 글자 9개, 정답 글자를 모두 포함)
- `speed` — `{ answer, ref, rows: [{ c, w }] }` (`w`에 `c`가 포함, `c`를 이으면 `answer`)
- `blank` — `{ ref, verse, answers: [], bank: [] }` (`verse`의 `{}` 개수 = `answers` 개수)

현장에서 급히 문제를 바꿀 때는 앱 안의 **✎ 문제 편집**을 쓰면 됩니다. 그 수정은 `localStorage`(`churchGames.custom.v1`)에만 저장되므로, 모든 기기에 반영하려면 `data.js`를 고쳐 다시 올립니다.
